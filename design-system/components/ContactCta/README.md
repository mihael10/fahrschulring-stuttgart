# ContactCta

Closing call-to-action band in solid green-500, placed right before the footer on content pages.

## Structure
- Ground `color-green-500`; centered, `space-6` gaps, vertical padding `space-16` / `space-20`.
- `section-title` in `color-green-950` (30px on mobile), one sentence of `body` in green-900 at 80%.
- A `dark` Button with the dark pulse ring, and an outlined phone pill (green-950 at 20% border, 10% fill on hover) with the ringing icon.

## The consumer provides
A question-style headline, one sentence on what happens next, phone number.

## Do / don't
- Never use a `primary` button here — it would vanish into the band.
- One per page, at the end.
