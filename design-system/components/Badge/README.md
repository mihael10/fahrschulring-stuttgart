# Badge

Translucent pill label that sits above the hero headline on green-950.

## When to use
One per hero, stating the strongest credential ("Seit über 50 Jahren in Stuttgart"). Only on dark grounds.

## The consumer provides
Short text as children (max ~40 characters).

## Do / don't
- Don't use it as a status chip or inside cards.
- Hand-ported from the inline badge in `src/components/Hero.tsx`.
