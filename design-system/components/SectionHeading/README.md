# SectionHeading

Centered eyebrow, H2 and optional description that opens every content section.

## When to use
At the top of each section, followed by `space-14` before a grid or `space-12` before a list. Set `light` on green-950 grounds.

## The consumer provides
`title` (required), `eyebrow` (a 1–3 word topic, written in normal case — it is rendered uppercase), `description` (one or two sentences, `body` style).

## Do / don't
- Keep titles to one idea, sentence case, no full stop unless it's a statement ("Gut zu wissen").
- Don't left-align it or stack two in one section.
- Ported from `src/components/SectionHeading.tsx`; the source's scroll `.reveal` animation is omitted here.
